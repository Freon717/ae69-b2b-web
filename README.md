# AE69 B2B — веб для проверки с телефона

**https://freon717.github.io/ae69-b2b-web/**

Полный каталог B2B (семьи, каскадные фасеты, поиск, корзина, избранное). **Оптовых цен здесь нет** — прайс только в защищённом клиенте `ae69-b2b-backend`.

Это не справочник сотрудника (`ae69-catalog-web`).

## Что проверить на iPhone / APK

1. Главная — поиск и ярлыки, не дубль каталога. Логотип всегда на главную.
2. Каталог → Провода и кабели → ПГВА. Одна карточка семейства.
3. Сечение **6,00 мм²** → длина → цвет. Нет белого, если его нет в прайсе. Смена длины меняет SKU.
4. После «В корзину» кнопка становится − / кол-во / +. Шаг 1, кроме голых клемм «мин.100» (шаг 100).
5. КГВВА: сечение → жилы → длина. Гофра: класс B/E → разрезная/неразрезная → диаметр → длина.
6. Поиск `6886`, `ПГВА 0,75`, `шестиместная колодка`.
7. Android Back возвращает на предыдущий экран.

Debug APK `ru.ae69.b2b.debug` открывает эту же ссылку в WebView.
