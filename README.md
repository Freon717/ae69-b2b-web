# AE69 B2B — веб для проверки с телефона

**https://freon717.github.io/ae69-b2b-web/**

Полный каталог B2B (семьи, фасеты, поиск, корзина). **Оптовых цен здесь нет** — прайс только в защищённом клиенте `ae69-b2b-backend`.

Это не справочник сотрудника (`ae69-catalog-web`).

## Что проверить на iPhone

1. Главная → Провода и кабели → ПГВА.
2. Сечение **6,00 мм²** → длина → цвет. Недоступные сочетания скрываются.
3. Поиск `7021` и `ПГВА 0,75`.
4. В корзину → степпер − / кол-во / +. Минус до нуля убирает строку.
5. Логотип — на главную. «Каталог» — корень каталога.

Debug APK `ru.ae69.b2b` открывает эту же ссылку в WebView.
