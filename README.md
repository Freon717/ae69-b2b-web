# AE69 B2B — веб для проверки

Тот же приём, что у справочника сотрудника:
https://freon717.github.io/ae69-catalog-web/

Эта ссылка после включения Pages:
**https://freon717.github.io/ae69-b2b-web/**

## Как открыть

1. Один раз в GitHub: репозиторий `ae69-b2b-web` → Settings → Pages → Source **GitHub Actions**.
2. Откройте ссылку в Chrome или Safari.
3. На iPhone: Поделиться → На экран «Домой».

## Что здесь есть

Каталог, семья ПГВА, фасеты сечение→длина→цвет, цена SKU, степпер корзины, CSV.
Остатки не показываются.

Пока нет файла `catalog.json` из бэкенда, стоит демо-выборка (ПГВА, КГВВА, АМГ, колодка, гофра) — её хватит, чтобы проверить логику без APK.

Полный прайс: скопируйте `ae69-b2b-backend/src/data/catalog.json` сюда как `catalog.json`.

Это **не** справочник сотрудника и **не** публичный прайс для всех. Для проверки витрины.
